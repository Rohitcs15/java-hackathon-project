# 🏦 Nexus Bank – Core Banking System (Java Console Project)

A fully functional **console-based banking system built using pure Java**.  
This project simulates real-world banking operations with role-based access (Admin & Customer), transaction management, and analytics.

---

## 🚀 Features

### 👨‍💼 Admin Features
- Create new bank accounts
- View all accounts
- Search accounts by name
- View account details & mini statement
- Freeze / unfreeze accounts
- Register customer login
- Apply monthly interest to all accounts
- View bank analytics & reports

### 👤 Customer Features
- View account summary
- Deposit money
- Withdraw money (with minimum balance check)
- Transfer funds to other accounts
- View mini statement (last 10 transactions)
- View full transaction history
